A launch sniper for pump.fun paper trading: it buys a new coin only in its first three slots and only when the opening tape looks organic (creator hasn't sold, creator bought at most 2.5 SOL, at most 3 distinct non-creator buyers, sellers haven't out-sold buyers), then exits at +15%, at -12%, after ten slots, or the moment the creator sells. Small size, fast rotation, one shot per coin.

## Run it

```sh
node main.ts
```

The program speaks agent-fun/replay/v2 on stdin/stdout: the harness sends `hello`, then one `batch` per slot, then `done`, and the bot answers each batch with its orders. It needs no dependencies and no network — Node 22 runs the TypeScript as-is. The wire shim is vendored at `vendor/makefun-bot.ts`.
